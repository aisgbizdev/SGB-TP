# 05 — History (Riwayat Analisa)

Halaman History menyimpan semua analisa yang pernah kamu buat — lengkap dengan fitur filter canggih dan preset untuk akses cepat.

---

## 5.1 Cara Masuk

Tap ikon **"Riwayat"** / **"History"** di navigation bar bawah.

---

## 5.2 Daftar Analisa

Setiap item di daftar menampilkan:

| Info | Keterangan |
|------|-----------|
| **Instrumen** | Nama aset yang dianalisa (misal: XAU/USD) |
| **Timeframe** | Timeframe analisa (misal: 4h) |
| **Tanggal & waktu** | Kapan analisa dibuat |
| **Mode badge** | Pemula atau Pro |
| **Outcome badge** | Win / Loss / Breakeven / Skipped / Belum ditandai |
| **Catatan** | Ikon 📝 muncul kalau ada catatan tersimpan |

Tap salah satu item untuk masuk ke **Analysis Detail**.

---

## 5.3 Search (Pencarian)

Di bagian atas ada kolom **Search** — ketik kata kunci untuk mencari analisa berdasarkan isi catatan atau nama instrumen.

- Maksimal 100 karakter
- Search real-time (tidak perlu tekan Enter)

---

## 5.4 Filter Analisa

Tap tombol **"Filter"** (ikon corong) untuk membuka panel filter.

### Filter yang Tersedia

| Filter | Opsi |
|--------|------|
| **Instrumen** | Pilih satu atau beberapa instrumen (XAU/USD, EUR/USD, BRENT, dll) |
| **Timeframe** | Pilih timeframe (1m, 5m, 15m, 30m, 1h, 4h, 1D, 1W) |
| **Tanggal Mulai** | Analisa dari tanggal tertentu |
| **Tanggal Akhir** | Analisa sampai tanggal tertentu |
| **Mode** | Filter berdasarkan mode (Pemula / Pro) |
| **Outcome** | Filter berdasarkan hasil (Win / Loss / Belum ditandai / dll) |

### Cara Menggunakan Filter
1. Tap **"Filter"**
2. Pilih kombinasi filter yang kamu mau
3. Filter langsung diterapkan
4. Tap ✕ di setiap chip filter aktif untuk menghapus satu filter
5. Tap **"Clear All"** untuk hapus semua filter sekaligus

---

## 5.5 Filter Presets 💾

**Apa itu:** Cara menyimpan kombinasi filter yang sering dipakai supaya tidak perlu set ulang setiap kali.

### Cara Simpan Preset
1. Set kombinasi filter yang kamu mau
2. Tap tombol **"Simpan Preset"** / **"Save Preset"**
3. Beri nama preset (misal: "Gold 4H Seminggu ini")
4. Tap **"Simpan"**

### Cara Pakai Preset
1. Tap dropdown preset di atas daftar filter
2. Pilih nama preset yang sudah disimpan
3. Filter langsung diterapkan

### Cara Rename Preset
1. Tap ikon pensil ✏️ di sebelah nama preset
2. Ketik nama baru
3. Tap **"Simpan"**

### Cara Hapus Preset
1. Tap ikon tempat sampah 🗑️ di sebelah nama preset
2. Konfirmasi hapus

> 💡 Preset berguna kalau kamu rutin review analisa Gold minggu lalu, atau mau lihat semua analisa yang hasilnya loss bulan ini.

---

## 5.6 Refresh Analisa

Setiap item analisa di History punya tombol **refresh (🔄)**. Tap untuk memperbarui data indikator teknikal dan fundamental analisa tersebut tanpa membuat analisa baru.

Berguna kalau kamu mau lihat apakah kondisi teknikal sudah berubah sejak analisa pertama dibuat.

---

## 5.7 Hapus Analisa

Untuk menghapus analisa dari riwayat:
1. Swipe item ke kiri (di mobile) atau tap tombol hapus 🗑️
2. Konfirmasi penghapusan

> ⚠️ Analisa yang dihapus tidak bisa dipulihkan. Pastikan kamu sudah tidak membutuhkannya.

---

## 5.8 Tips Penggunaan History

- **Review mingguan:** Pakai filter tanggal untuk lihat semua analisa minggu lalu dan bandingkan dengan outcome
- **Identifikasi pola:** Filter berdasarkan outcome "Loss" lalu lihat instrumen/timeframe apa yang paling sering salah
- **Bandingkan timeframe:** Buat preset untuk setiap timeframe favoritmu dan bandingkan akurasi
