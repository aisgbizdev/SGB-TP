# 01 — Getting Started

Panduan ini menjelaskan cara membuat akun, masuk ke app, menangani lupa password, dan menyesuaikan pengaturan dasar.

---

## 1.1 Daftar Akun Baru

### Langkah-langkah

1. Buka TradePilot di browser atau install sebagai PWA (lihat [Tips Install PWA →](./15-tips-and-faq.md))
2. Klik tombol **"Daftar"** atau **"Sign Up"** di halaman login
3. Isi formulir pendaftaran:

| Field | Keterangan | Contoh |
|-------|-----------|--------|
| **Email** | Alamat email aktif kamu | `kamu@gmail.com` |
| **Nama Tampilan** | Nama yang muncul di profil (min. 2 karakter) | `Budi` |
| **Password** | Minimal 6 karakter | `trading123` |
| **Mode** | Pilih level pengalaman kamu | Pemula / Pro |
| **Pertanyaan Keamanan** | Dipilih dari daftar | Nama hewan peliharaan pertama |
| **Jawaban** | Jawaban untuk pertanyaan di atas (min. 2 karakter) | `Putih` |

4. Klik **"Buat Akun"**
5. Kamu langsung masuk dan diarahkan ke **Dashboard**

> ⚠️ **Simpan jawaban keamananmu!** Ini satu-satunya cara reset password kalau kamu lupa. Tidak ada verifikasi email.

---

## 1.2 Login

1. Buka TradePilot
2. Masukkan **Email** dan **Password** kamu
3. Klik **"Masuk"**
4. Kamu diarahkan ke **Dashboard**

> 💡 Kalau akun belum ada, klik link **"Daftar"** di bawah tombol masuk.

---

## 1.3 Lupa Password

TradePilot tidak menggunakan verifikasi email. Reset password dilakukan lewat **pertanyaan keamanan** yang kamu set saat daftar.

### Langkah-langkah

**Step 1 — Masukkan Email**
1. Di halaman login, klik **"Lupa password?"**
2. Masukkan email akun kamu
3. Klik **"Lanjut"**

**Step 2 — Jawab Pertanyaan Keamanan**
1. Pertanyaan keamanan kamu akan muncul
2. Masukkan jawaban yang kamu daftarkan
3. Klik **"Verifikasi"**

**Step 3 — Set Password Baru**
1. Masukkan password baru (min. 6 karakter)
2. Ulangi password baru untuk konfirmasi
3. Klik **"Reset Password"**
4. Kamu langsung masuk ke Dashboard

> ⚠️ Kalau kamu lupa jawaban keamanan, tidak ada cara lain untuk memulihkan akun. Hubungi admin TradePilot.

---

## 1.4 Onboarding — Pilih Mode

Saat pertama kali masuk setelah daftar, kamu akan melihat **Onboarding Modal** — dialog 4 langkah yang memperkenalkan fitur utama TradePilot.

### 4 Langkah Onboarding

| Langkah | Topik |
|---------|-------|
| 1 | Cara kerja analisa AI TradePilot |
| 2 | Fitur edukasi & mindset |
| 3 | Statistik & performa analisa |
| 4 | Mulai! |

- Klik **"Lanjut"** untuk maju ke langkah berikutnya
- Klik **"Lewati"** kalau mau langsung ke Dashboard

> 💡 Onboarding hanya muncul sekali per akun. Kamu bisa ganti mode kapan saja dari Dashboard.

### Mode Pemula vs Pro

| Aspek | Pemula | Pro |
|-------|--------|-----|
| **Tampilan analisa** | Lebih simpel, bahasa mudah | Lengkap, semua detail terlihat |
| **Target pengguna** | Baru belajar trading | Sudah paham teknikal & fundamental |
| **Indikator teknikal** | Disederhanakan | Full panel |
| **Trade Plan** | Ditampilkan dengan penjelasan | Langsung ke angka |

Cara ganti mode:
1. Buka **Dashboard**
2. Klik kartu mode di bagian atas ("Kamu di mode **Pemula**")
3. Pilih mode yang baru

---

## 1.5 Ganti Bahasa

TradePilot mendukung **Bahasa Indonesia** dan **English**.

Cara ganti:
1. Buka halaman **Profil** (ikon orang di navigation bar bawah)
2. Scroll ke bagian **Bahasa**
3. Pilih **Indonesia** atau **English**

Perubahan langsung berlaku tanpa reload.

> 💡 Di halaman Login dan Daftar, ada tombol ganti bahasa di pojok kanan atas — kamu bisa ganti sebelum masuk ke app.

---

## 1.6 Install Sebagai Aplikasi (PWA)

TradePilot adalah PWA (Progressive Web App) — bisa diinstall di HP seperti aplikasi biasa.

### Di Android (Chrome)
1. Buka TradePilot di browser Chrome
2. Tap menu ⋮ (titik tiga) → **"Add to Home Screen"** / **"Install App"**
3. Konfirmasi install

### Di iPhone (Safari)
1. Buka TradePilot di Safari
2. Tap ikon Share (kotak dengan panah ke atas)
3. Pilih **"Add to Home Screen"**
4. Tap **"Add"**

Setelah diinstall, app berjalan dalam mode standalone (tanpa browser bar) dan push notification bekerja lebih optimal.
